# ⚠️ لایه Hybrid / Self-bot — پلاگین اختیاری و ایزوله

**این لایه بهطور پیشفرض غیرفعال است و هرگز بهصورت خودکار نصب یا فعال نمیشود.**

## چرا ایزوله است؟

- self-bot از **Internal API** بله (reverse-engineered، بدون مستندات رسمی) استفاده میکند.
- نیاز به **لاگین با شماره تلفن و کد SMS** دارد، نه توکن `@botfather`.
- طبق issue مطرحشده در مخزن aiobale، یک workflow اسرار را به IP خارجی POST میکند. ما آن ادعا را تأیید مستقل نکردهایم، اما به همین دلیل این لایه را جدا و غیرفعال نگه میداریم.
- استفاده از self-bot میتواند منجر به **بسته شدن اکانت شخصی** شود.

## اصول BADKING در این لایه

1. **هیچ وابستگی self-bot در نصب پیشفرض وجود ندارد.**
2. **اسرار در keyring سیستم ذخیره میشوند**، نه در فایل `.bale` ساده.
3. **همان Dispatcher و همان هندلرها** روی هر دو lane (رسمی و self-bot) کار میکنند.
4. **اگر internal API خراب شود، lane رسمی سر جایش میماند** و ربات نمیمیرد.
5. **هشدار صریح** هنگام فعالسازی چاپ میشود.

## وضعیت فعلی

رابط `HybridPlugin` و چارچوب ایزولاسیون پیادهمسازی شدهاند. پیادهسازی کامل 80+ RPC مربوط به internal API بهصورت پلاگین جداگانه و post-release انجام میشود (ریسک بالا، نیاز به reverse engineering مداوم).

برای فعالسازی آگاهانه:

```python
from badking.hybrid import HybridPlugin, hybrid_warning

print(hybrid_warning())
plugin = HybridPlugin(enabled=True, ack_risk=True)  # بدون ack_risk فعال نمیشود
```
