# Installation

```bash
pip install badking
```

Optional extras:

```bash
pip install badking[redis]      # RedisStorage
pip install badking[postgres]   # PostgreSQLStorage
pip install badking[hybrid]     # self-bot (websockets)
pip install badking[all]
```

Python 3.9 or newer.

## Verify

```bash
badking info
badking doctor
```
