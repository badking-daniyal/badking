# FAQ

**Does BADKING support self-bot?** Yes, in `badking.hybrid`. It is disabled by
default and carries account-ban risk.

**Is it a copy of aiobale?** No. It is an independent implementation with a
migration path. See `docs/COMPETITIVE_ANALYSIS.md`.

**Can I use it on Python 3.8?** No. 3.9+.

**Is the RPC schema verified?** No — BLOCKED without a live account.

**Does it publish to PyPI?** Not yet.
