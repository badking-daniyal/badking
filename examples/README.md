# نمونه‌ها

۲۲ نمونه اجراشدنی. از سه خط تا ربات تولیدی.

هر فایل با `python` اجرا می‌شود و در بالای خودش می‌گوید چه کار می‌کند و
چه چیزی لازم دارد. همه از نظر نحوی و import تست می‌شوند
(`tests/test_examples.py`).

## شروع

```bash
pip install badking

# ویندوز
set BADKING_TOKEN=123456:ABC...
# لینوکس و مک
export BADKING_TOKEN=123456:ABC...

python examples/01_hello.py
```

توکن را از @botfather در بله بگیر.

## از کجا شروع کنم

**تازه‌کار:** ۰۱ → ۰۲ → ۰۳. سه فایل، نیم ساعت.

**کسب‌وکار:** ۰۸ (فروشگاه) یا ۰۷ (پشتیبانی). هر دو کامل‌اند.

**تولید:** ۲۰. ساختار، خاموشی ایمن، متریک، پیکربندی از محیط.

**Self-bot:** ۱۱ → ۱۲ → ۱۴. به ترتیب.

## قاعده‌ها

- توکن در کد نیست. از محیط خوانده می‌شود.
- هر نمونه در بالای خودش می‌گوید چه لازم دارد.
- نمونه‌های self-bot `ack_risk=True` دارند و بدون آن روشن نمی‌شوند.
- هیچ نمونه‌ای توکن واقعی ندارد (`tests/test_examples.py` این را می‌پاید).
